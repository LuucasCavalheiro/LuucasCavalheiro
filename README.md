## 🚀 Projetos em destaque

### 💈 [Agenda Barbearia Cavalheiros](https://github.com/LuucasCavalheiro/Agenda-Barbearia-Cavalheiros)
Aplicação desktop desenvolvida em **Python + PyQt5** para gerenciamento real de uma barbearia.

**Recursos já implementados:**
- agenda de atendimentos e controle de horários;
- cadastro e histórico de clientes;
- serviços, produtos e formas de pagamento;
- controle de caixa diário;
- lista de espera e pacotes de serviços;
- backups e restauração de dados;
- mensagens de confirmação via WhatsApp;
- avisos de aniversários e feriados.

> Este projeto representa minha evolução de scripts simples para uma aplicação usada em um cenário real.

## 🌱 Próximo grande projeto

### Sistema Cavalheiros

A próxima etapa será transformar a experiência adquirida com a aplicação desktop em um sistema web completo.

Planejamento inicial:

```text
Aplicação desktop atual
        ↓
Banco de dados relacional
        ↓
Backend web em Python
        ↓
Painel administrativo
        ↓
Site da barbearia
        ↓
Agendamento online
```

O objetivo é evoluir o projeto aos poucos, documentando arquitetura, decisões técnicas, issues, branches, pull requests e versões diretamente no GitHub.
